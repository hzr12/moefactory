# 车厢延误预测系统

这是一个基于深度学习和机器学习的车厢延误预测系统，使用多种模型集成的方式来提高预测准确性。

## 项目概述

本项目旨在使用AI模型预测车厢延误情况，以提升列车运行调度效率和乘客服务质量。项目采用多种深度学习和传统机器学习模型，并通过加权集成的方式融合各模型的优势进行预测。

## 系统功能

- 数据预处理：解析CSV格式的列车运行数据
- 模型训练：支持多种深度学习和传统机器学习模型训练
- 模型预测：基于训练模型对测试数据进行预测
- 集成学习：使用加权集成模型融合多个基础模型的预测结果
- 结果输出：将预测结果保存为CSV文件

## 技术架构

项目采用模块化设计，主要包括以下几个模块：

1. **data_preprocess.py** - 数据预处理模块
2. **models.py** - 基础模型定义模块
3. **train.py** - 基础模型训练模块
4. **predict.py** - 基础模型预测模块
5. **advanced_ensemble.py** - 高级集成模型定义
6. **train_weighted_ensemble.py** - 加权集成模型训练
7. **predict_weighted_ensemble.py** - 加权集成模型预测

## 特征工程增强

为了在不增加训练数据的情况下提高预测准确性，我们实施了以下特征工程增强策略：

### 1. 时间特征增强
- 添加时间段特征（高峰期、时间段分段）
- 添加日期相关特征（是否周末、是否月初/月末、季节）
- 添加周期性时间编码（使用正弦和余弦函数对小时、星期、月份进行编码）

### 2. 历史统计特征
- 车站历史延误统计特征（均值、标准差、最小值、最大值）
- 过去3站的延误滚动统计特征（均值、标准差）

### 3. 延误传播特征
- 前序站点延误时间
- 累计延误时间

### 4. 分类特征处理
- 使用LabelEncoder对车站名进行编码

### 5. 特征选择
- 选择对列车延误预测最有价值的特征组合

## 模型介绍

本项目使用多种模型来预测车厢延误时间，包括：

1. **深度学习模型**：
   - Transformer模型
   - LSTM模型
   - Seq2Seq模型
   - 集成模型（平均集成）

2. **传统机器学习模型**：
   - 随机森林（Random Forest）
   - LightGBM
   - XGBoost
   - CatBoost

3. **高级集成模型**：
   - 加权集成模型（Weighted Ensemble）：通过学习各子模型的权重来集成预测结果

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 基础模型训练

```bash
python train.py
```

该命令会训练所有基础模型，包括深度学习模型和传统机器学习模型。

### 3. 基础模型预测

```bash
python predict.py
```

该命令会使用所有已训练的基础模型对测试数据进行预测，并保存各自的预测结果。

### 4. 加权集成模型训练

```bash
python train_weighted_ensemble.py
```

该命令会训练加权集成模型，学习各个子模型的权重。

### 5. 加权集成模型预测

```bash
python predict_weighted_ensemble.py
```

该命令会使用加权集成模型对测试数据进行预测。

## 输出结果

预测结果将保存在 `predictions/` 目录下，每个模型的预测结果保存在独立的文件中，文件名包含模型名称。

## 特点

1. **多模型集成**：结合深度学习和传统机器学习模型的优势
2. **动态权重学习**：加权集成模型可以自动学习各子模型的权重
3. **可扩展性**：易于添加新的模型或特征
4. **鲁棒性**：通过集成多个模型提高预测的稳定性

## 数据格式

### 训练数据格式
训练数据位于 `./datasets/train` 目录下，包含多个CSV文件，每个文件记录一趟列车的信息：
```
车次ID,车站名,到达日期,到达时间,出发日期,出发时间,延误分钟
G339,北京西,2025-08-16,12:26,2025-08-16,12:26,-1
...
```

### 测试数据格式
测试数据位于 `./datasets/test` 目录下，包含需要预测的未来数据：
```
车次ID,车站名,到达日期,到达时间,出发日期,出发时间
G339,北京西,2025-08-25,12:26,2025-08-25,12:26
...
```

## 预测结果说明

预测结果中的"预测延误分钟"表示列车延误的时间（分钟）：
- 正数表示列车将晚点x分钟
- 负数表示列车将早到|x|分钟
- 0表示列车将准点到达

## 训练和预测流程

1. 将训练数据放在 `datasets/train/` 目录下
2. 运行 `python train.py` 训练基础模型
3. 运行 `python train_weighted_ensemble.py` 训练加权集成模型
4. 将测试数据放在 `datasets/test/` 目录下
5. 运行 `python predict_weighted_ensemble.py` 进行预测
6. 预测结果将保存在 `predictions/` 目录下
