# 列车延误预测系统

本项目使用PyTorch构建AI模型来预测列车的正晚点信息。

## 项目结构

```
.
├── datasets/
│   ├── train/          # 训练数据
│   └── test/           # 测试数据
├── model/              # 模型保存目录
├── predictions/        # 预测结果保存目录
├── data_preprocess.py  # 数据预处理模块
├── models.py           # 模型定义
├── train.py            # 训练脚本
├── predict.py          # 预测脚本
├── requirements.txt    # 项目依赖
└── README.md           # 说明文档
```

## 数据格式

### 训练数据格式
训练数据位于 `./datasets/train` 目录下，包含多个CSV文件，每个文件记录一趟列车的信息：
```
车次ID,车站名,到达日期,到达时间,出发日期,出发时间,延误分钟
G339,北京西,2025-08-16,12:26,2025-08-16,12:26,-1
...
```

### 测试数据格式
测试数据位于 `./datasets/test` 目录下，包含需要预测的未来数据：
```
车次ID,车站名,到达日期,到达时间,出发日期,出发时间
G339,北京西,2025-08-25,12:26,2025-08-25,12:26
...
```

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 训练模型

```bash
python train.py
```

训练完成后，模型将保存在 `./model` 目录下。

### 2. 进行预测

```bash
python predict.py
```

预测结果将保存在 `./predictions/prediction_results.csv` 文件中，格式如下：
```
车次ID,车站名,出发日期,出发时间,预测延误分钟
G339,北京西,2025-08-25,12:26,0
...
```

## 模型架构

本项目实现了多种深度学习模型和传统机器学习模型：

1. **Transformer模型** - 使用自注意力机制捕捉时间序列特征
2. **LSTM模型** - 使用长短期记忆网络处理序列数据
3. **Seq2Seq模型** - 使用编码器-解码器结构进行预测
4. **集成模型** - 综合以上三种模型的预测结果
5. **随机森林模型** - 传统机器学习模型，用于对比和集成
6. **LightGBM模型** - 高效的梯度提升框架

## 特征工程

从原始数据中提取了以下特征：
- 出发时间（小时、分钟）
- 出发日期（月份、日期、星期）
- 车站名（标签编码）

## 预测结果说明

预测结果中的"预测延误分钟"表示列车延误的时间（分钟）：
- 正数表示列车将晚点x分钟
- 负数表示列车将早到|x|分钟
- 0表示列车将准点到达
