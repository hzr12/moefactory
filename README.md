基于PyTorch和多种机器学习算法的列车延误预测系统，用于分析列车运行历史数据并预测延误情况。

## 项目概述

该系统旨在通过分析列车运行历史数据来预测列车延误情况，帮助铁路运输管理部门优化调度决策，提升乘客服务质量。系统采用多种深度学习和传统机器学习模型进行预测，并通过模型集成技术提高预测准确性。

## 功能特性

- **多模型支持**：支持Transformer、LSTM、Seq2Seq等多种深度学习模型，以及随机森林、LightGBM、XGBoost、CatBoost等传统机器学习模型
- **数据预处理**：完整的特征工程，包括时间特征提取、车站编码等
- **模型训练**：支持训练多种模型并自动保存最佳模型
- **模型预测**：基于训练模型进行延误预测
- **模型集成**：提供加权集成策略，根据模型在验证集上的表现动态分配权重
- **增量训练**：支持在已有模型基础上进行增量训练
- **批量预测**：支持对多个测试文件进行批量预测

## 技术架构

系统采用模块化设计，主要包括以下组件：

- **数据预处理模块**：负责数据加载、特征工程和数据编码
- **模型定义模块**：包含各种深度学习和传统机器学习模型的实现
- **训练模块**：实现模型训练逻辑，包括早停机制和学习率调度
- **预测模块**：基于训练好的模型进行预测
- **集成模型模块**：实现模型集成策略和权重分配

## 数据格式

### 训练数据
训练数据应放在 `datasets/train/` 目录下，支持多个CSV文件。每行代表一个列车在特定车站的记录，包含以下字段：

- `车次ID`: 列车班次标识
- `车站名`: 车站名称
- `出发日期`: 出发日期 (格式: YYYY-MM-DD)
- `出发时间`: 出发时间 (格式: HH:MM)
- `到达时间`: 到达时间 (格式: HH:MM)
- `延误分钟`: 实际延误分钟数 (目标变量)

### 测试数据
测试数据应放在 `datasets/test/` 目录下，支持多个CSV文件。格式与训练数据类似，但不包含`延误分钟`字段。

## 使用方法

### 训练模型

训练所有模型（包括深度学习模型和传统机器学习模型）：

```bash
python train.py
```

训练集成模型（计算各模型权重）：

```bash
python train_integrated_ensemble.py
```

训练完成后，模型将保存在 `model/` 目录下。

### 增量训练

在已有模型基础上进行增量训练：

```bash
python incremental_train.py
```

### 预测

使用所有模型进行预测：

```bash
python predict.py
```

使用集成模型进行预测：

```bash
python predict_integrated_ensemble.py
```

预测结果将保存在 `predictions/` 目录下。

## 模型说明

系统包含以下模型：

### 深度学习模型
1. **Transformer模型**：基于Transformer架构的预测模型
2. **LSTM模型**：基于长短期记忆网络的序列模型
3. **Seq2Seq模型**：基于编码器-解码器架构的序列到序列模型
4. **集成模型**：将上述三种深度学习模型进行集成

### 传统机器学习模型
1. **随机森林**：基于决策树的集成学习模型
2. **LightGBM**：基于梯度提升框架的高效模型
3. **XGBoost**：优化的分布式梯度提升库
4. **CatBoost**：支持分类特征的梯度提升算法

### 集成策略
系统采用加权平均方法集成不同模型的预测结果。权重根据各模型在验证集上的表现动态计算，表现越好的模型分配的权重越高。

## 结果输出

预测结果将保存在 `predictions/` 目录下，每个模型对每个测试文件都会生成一个预测结果文件，文件命名格式如下：

- 单模型预测：`prediction_results_{model_name}_{test_file_name}.csv`
- 平均集成预测：`prediction_results_average_{test_file_name}.csv`
- 加权集成预测：`prediction_results_integrated_ensemble_{test_file_name}.csv`

预测结果文件包含以下字段：
- `车次ID`: 列车班次标识
- `车站名`: 车站名称
- `出发日期`: 出发日期
- `出发时间`: 出发时间
- `预测延误分钟`: 预测的延误分钟数（整数）
